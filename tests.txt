1   вызов справки — при запуске без параметров и с параметром --help;
ввод:python mathtool.py
вывод:mathtool - решение уравнения вида A*x^2+B*x+C = 0

Использование: 
 
   python mathtool.py                         вывод справки
   python mathtool.py --help                  вывод справки
   python mathtool.py solve                   ввод коэффициентов с клавиатуры 
   python mathtool.py solve -a X -b X -c X    решение с задаными коэффициентами

Коэффициенты A, B, С - целые числа, по модулю не превышающие 10000


2   указание неизвестной команды вместо solve;
ввод:python mathtool.py run
вывод:Ошибка: неверная команда


3   неверный набор параметров — пропущенный, лишний или неизвестный параметр;
ввод: python mathtool.py solve -a -b 2 -c 4
вывод:Ошибка: неверная команда


4	исходные данные не являются числами;
ввод:python mathtool.py solve -a 0 -b asd -c 8
вывод:Ошибка: числа должны быть целыми


5	исходные данные выходят за допустимый диапазон;
ввод:python mathtool.py solve -a 11111 -b 5 -c 8
вывод:Ошибка: значение вне допустимого диапазона


6	квадратное уравнение с двумя корнями;
ввод: python mathtool.py solve  
Введите A: 11
Введите B: 5
Введите C: -9
вывод:Уравнение квадратное
Дискриминант:  421
x1 = 0.705 x2 = -1.160


7	квадратное уравнение с одним корнем;
ввод:python mathtool.py solve -a 3 -b 6  -c 3 
вывод:Уравнение квадратное
Дискриминант:  0
x = -1.000


8	квадратное уравнение без действительных корней;
ввод:python mathtool.py solve -a 1 -b 5 -c 8 
вывод:Уравнение квадратное
Дискриминант:  -7
Действительных корней нет


9	линейное уравнение с одним корнем;
ввод:python mathtool.py solve -a 0 -b 6  -c 13 
вывод:Уравнение линейное
x = -2.167


10	A = 0 и B = 0 — неизвестного нет, уравнения не существует при любом C; сообщение об ошибке и код возврата 1.
ввод:python mathtool.py solve -a 0 -b 0  -c 312 
вывод:Ошибка: это не уравнение, неизвестное отсутствует
